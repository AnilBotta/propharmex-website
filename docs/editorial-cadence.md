# Monthly Editorial Cadence

This note defines the monthly draft workflow for Propharmex editorial content. It is intentionally review-first: automation prepares packets, but public publishing remains a human editorial, regulatory, and brand decision.

## Cadence

- Runs on the first Monday of each month at 9:00 AM America/Toronto.
- Produces one draft packet with four sections:
  - Article topic and outline.
  - Regulatory update source pack and draft summary.
  - Whitepaper outline or refresh proposal.
  - Case-study refresh proposal based only on existing anonymized case studies.
- Output is for review. It must not publish to the website, Sanity, email, or social channels automatically.

## Approval Gates

- Regulatory updates must use primary sources only: ICH, Health Canada, USFDA, WHO, EMA, TGA, or PMDA.
- Every regulatory claim needs an "as of" date and an informational disclaimer.
- Case-study updates must use existing anonymized case-study facts unless Propharmex provides a new approved engagement brief.
- Whitepaper drafts need an approved topic, source posture, and final brand-voice review before a PDF is generated or published.
- All copy must avoid retired study-execution positioning outside analytical-method review, unsupported licence claims, facility claims, approval promises, and invented client metrics.

## Monthly Packet Format

Each monthly packet should include:

- Recommended publish priority and rationale.
- Source list with primary-source URLs for regulatory material.
- Claim-risk notes, including any sentence that needs user confirmation.
- Draft title, meta title, meta description, target persona, pillar, and CTA.
- Internal-link suggestions to relevant service pages, insights, and case studies.
- A "do not publish until" checklist covering brand, regulatory, and client-anonymization review.
